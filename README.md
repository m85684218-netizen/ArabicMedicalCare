# سجل التاريخ الطبي الشخصي (نموذج تجريبي)

واجهة عربية (RTL) مبنية بـ HTML5 و CSS3 و JavaScript فقط، بدون أي إطار عمل أو سيرفر.

## التشغيل
افتح `index.html` في المتصفح مباشرة. حافظ على ترتيب الفولدرات: `css/` و `js/` بجوار `index.html`.

## التخزين
تُحفظ البيانات في LocalStorage بالمفتاح `medicalRegistry.v2` داخل هذا المتصفح فقط. من الإعدادات يمكن استعادة البيانات التجريبية.
حقل الرقم القومي: 14 رقمًا، إلزامي، ولا يتكرر بين شخصين.

## تنبيه مهم
هذا نموذج تجريبي ببيانات وهمية فقط. LocalStorage غير مشفّر وغير آمن، ولا يصلح لبيانات مرضى أو أرقام قومية حقيقية.
